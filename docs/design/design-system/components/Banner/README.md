A soft strip under the toolbar for notices. The consumer provides the message and at most one action.

- Show at most two at once, in this order: no connection, Google Calendar problem, end-of-day Check in, block reminder, time zone, overload, turn on reminders. The rest wait behind "More notices (n)".
- Each variant leads with a bold phrase or an icon; never colour alone. Errors use `role="alert"`, others `role="status"`.
- No countdowns, streaks or alarm badges.
