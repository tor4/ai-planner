A block is a task, or part of one, placed at a time on the calendar; the same component draws hard events and the recovery buffer. Modifiers: none (planned), `--hard`, `--buffer`, `--proposed`, `--missed`, `--confirmed`, `--closed`.

- The consumer provides the title (bold sans) and the time line (mono, in `small`), and sets the height from the block's length. Short blocks cut the title with an ellipsis; the full text stays in the accessible name, which ends with the state.
- Shape carries state before colour: a rounded `citron-deep` bar (planned, unconfirmed), dashed outline (proposed, assistant suggestion), hatching (hard event, buffer), heavy outline (missed), paper card with ✓ (confirmed), dashed and faded (window closed). Icons ● ⊘ ✓ ! ✦ and the state word always appear.
- Text is 14px at least. The buffer is not focusable and reads "Recovery buffer, 10 minutes".
