The ink pill that follows deleting a block or task, Not now, marking a task done and ending a series. The consumer provides the latest action's text and the count.

- Shows 15 seconds (at least 10); pauses on focus or hover. Later actions join it as an ordered list. "Undo all" is the citron button.
- Ctrl+Z (Cmd+Z) undoes the newest action outside text fields.
- Offline it reads "Can't undo while offline" and its buttons are disabled.
